## Engineer → PM → Builder of Things That Matter 🚀

Hey there! 👋 I'm **Vishal Sharma** — a builder at heart who loves creating things that make a positive dent in the world.

### The TL;DR on Me

For the past **4+ years**, I've been on an adventure at [SigNoz](https://signoz.io) (YC W21), helping grow it from zero to an open-source observability platform trusted by thousands of teams. I started as the **first backend engineer**, built core systems handling *billions of traces*, and eventually shape-shifted into **Product Manager**. Yeah, I'm that guy who can debug your database *and* debate your roadmap. 😄

### Some highlights from the journey 🚀

- **40x** improvement in trace database(clickhouse) performance (yes, forty times!)
- Led **300+** user calls - demos, feedback sessions, and a lot of debugging "why isn't my data showing up?"
- Insights from user calls and some magic helped boost user activation by **40%** and average revenue per account by **45%**
- Built and launched the SigNoz SaaS platform
- Published **100+** technical blogs/docs with sample code on OpenTelemetry to help developers get started

Before SigNoz, I was at **OkCredit** building high-throughput systems (500k+ rpm, no pressure 🙃), won **2 hackathons**, and earned the "Best Newbie" 🏆 award. I was also into **ML/AI before it was cool** — built drone software at IIT Madras, trained deep learning models, and created a [COVID-19 predictor](https://www.medrxiv.org/content/10.1101/2021.03.02.21252269v1) with 98% accuracy during the pandemic.
